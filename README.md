# Конвертер валют

Простой конвертер валют на чистом JavaScript (без зависимостей). Работает в браузере и в Node.js.

## Возможности

- Пересчёт между валютами по фиксированным курсам
- Выбор валют из списка (с русскими названиями)
- Обмен валют местами (swap)
- Валидация суммы (отрицательные, NaN, Infinity, пусто)
- Встроенные self-тесты (кнопка «Тесты»)
- Форматирование денег

## Файлы

- `index.html` — интерфейс (тёмная тема)
- `app.js` — логика конвертера + self-тесты
- `rates.js` — курсы валют и функция `convert`

## Запуск

Открой `index.html` в браузере. Или:

```bash
node app.js
